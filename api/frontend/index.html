Inside the system

How the model works

The system uses a Transformer neural machine translation model. It processes the source sentence as subword tokens and generates a target sentence in Afaan Oromo, using patterns learned from paired Amharic–Afaan Oromo examples.

01

Input text

You enter a sentence written in Amharic. Empty input is rejected before the request is sent.

02

Subword tokenization

A SentencePiece Unigram tokenizer breaks text into reusable subword units from a shared 10,000-token vocabulary.

03

Transformer model

The encoder represents the Amharic context; the decoder uses that context to generate Afaan Oromo tokens in sequence.

04

Generated translation

The generated tokens are converted back into readable Afaan Oromo text and returned by the API.

i

Which topics does it perform best on?

The training data covers seven domains, so results may be stronger on wording and topics represented well in that data. The current overall BLEU and chrF scores do not identify a proven best-performing domain. Domain-by-domain test scores are needed before claiming that it performs best on education, health, news, or another specific topic.

Use it thoughtfully

Where it may help—and where to be careful

This is a text-only, one-direction research prototype: Amharic to Afaan Oromo. Its quality depends on input clarity, terminology, and how closely a sentence resembles examples available during training.

✓

Good starting points

  • Short, clear, grammatically complete sentences.
  • Everyday written communication and general text similar to the training examples.
  • Draft translations that a fluent Afaan Oromo speaker can review.
!

Needs extra review

  • Medical, legal, financial, or other high-stakes content.
  • Long, ambiguous, misspelled, highly idiomatic, or dialect-specific text.
  • Names, numbers, dates, and specialist terminology—verify them carefully.

Transparent by design

A helpful first draft—not a substitute for human review.

Machine translation can miss meaning, tone, or context. For formal publication or important decisions, ask a fluent speaker to review the output. This prototype currently translates only from Amharic into Afaan Oromo; it does not offer reverse translation or speech input.
